# Places of Interest

A web application for discovering and managing places of interest across Ireland.

This project is being developed as part of the Web Application Development module at SETU.

## Technologies

- Node.js
- Hapi
- Handlebars
- Bulma CSS
- JavaScript (ES Modules)
- ESLint (Airbnb Base)
- Prettier

## Installation

1. Clone the repository:

   ```bash
   git clone git@github.com:pmooney20-art/webapp1.git
   ```

2. Navigate to the project directory:

   ```bash
   cd webapp1
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the application:

   ```bash
   npm start
   ```

5. Open `http://localhost:3000` in a browser.

## Current Features

- Basic Hapi web server
- Handlebars templating with a shared layout
- Bulma styling and navigation
- Homepage
- Dashboard
- Places listing with sample data
- Separate routes and controllers
- ESLint and Prettier configuration
